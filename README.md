## Description
Five separate HTML pages demonstrate HTML forms, built-in HTML5 validation, Bootstrap form styling, Bootstrap validation classes, and a responsive registration form.

## Pages
- `task0.html` — simple contact form
- `task1.html` — HTML5 validation
- `task2.html` — Bootstrap grid and form classes
- `task3.html` — Bootstrap validation feedback
- `task4.html` — responsive registration form with password matching

## How to run
Open `index.html` in a browser, or run with VS Code Live Server. Internet connection is needed to load Bootstrap from CDN.

## Files
`index.html`, `task0.html`–`task4.html`, `style.css`, `script.js`.

## Notes
This is a front-end demonstration. Forms do not store or transmit submitted data.
